# SISReservasEspacios
# Sistema de Reservas de Espacios  Sistema web para gestionar la reserva y disponibilidad de diferentes espacios según fecha y horario. Permite administrar espacios, usuarios y reservas, validando conflictos de horarios y controlando el estado de cada reserva.  **Tecnologías:** C#, ASP.NET Core Web API, React, Entity Framework Core y SQL Server.
